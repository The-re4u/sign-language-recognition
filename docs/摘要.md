### 一、研究背景与目的

手语是全球超过7,000万听障人士的主要沟通方式，在中国约有2,000万听力障碍者以手语为母语。对手语母语者而言，键盘输入需经历"手语概念→汉语语法→文字编码"的双重认知转换，表达效率低下——尤其对先天听障和老年聋人群体，手语是其唯一熟练掌握的语言系统，文字输入等同于使用外语。当前五类辅助方案均存在显著局限：专业手语翻译员全国仅约1万人（与需求比1:2,000）、移动翻译应用仅支持孤立词识别、文字输入交流速度仅为自然手语的六分之一、穿戴式手套系统硬件昂贵、学术型视觉识别系统依赖GPU且输出仅为类别标签。近年来，Google MediaPipe等无标记姿态估计框架使在普通RGB摄像头上实时提取21个手部三维关键点成为可能。本文旨在设计并实现一套基于MediaPipe的轻量化多模态实时手语识别系统，以"双手组合编码"为核心交互范式，在普通RGB摄像头和CPU环境下实现从连续手势到自然中文语句的完整转换，以医院导诊为验证场景。

### 二、研究方法

系统采用七层流水线架构将原始视频帧逐步转化为自然中文语句：

**感知层**：MediaPipe HandLandmarker提取双手各21个三维关键点坐标，通过首帧手腕归一化消除摄像头距离偏差，检测速度>30 FPS。

**特征提取层**：三模态并行编码。Image模态——MobileNetV3-Small CNN在96×96手部ROI上提取512维RGB视觉纹理特征；Skeleton模态——SpatialGCN（图卷积网络）编码手部骨骼拓扑结构，HandShapeContext（29维几何描述子+MiniPointNet）提取手指角度/比例/分布的显式几何特征；Semantic模态（新增）——SemanticProjector将融合特征投影至语义原型空间，通过InfoNCE对比损失实现视觉-语义跨模态对齐。CNN与几何特征经GatedFusion（门控融合模块）逐维动态选择——门控网络学习gate = σ(MLP([cnn; geo_proj]))，每维独立判断"信RGB纹理还是信骨架几何"，解决传统加性融合的语义空间不兼容问题。三模态经CrossModalFusion（2层Transformer编码器）融合为256维统一表示。

**时序建模层**：SlowFast TCN（0.7M参数）采用双路径设计——Slow路径（大核+膨胀卷积，感受野43帧≈1.7秒）捕获手势完整生命周期，Fast路径（小核+高分辨率）保留细粒度指间动态，侧向连接实现跨尺度融合。时间均值池化+交叉熵损失完成序列级分类。

**规则识别层**：基于手指关节角度（>165°为伸直阈值）的几何判定树，引入PIP关节误差补偿（以更可靠的MCP关节辅助校验），满足可解释AI（XAI）框架，零参数、<1ms推理。

**语义解析层**：核心创新为双手组合编码协议——非惯用手持模式手势选择七个语义层（数字/常用语/病症/身体/医院/程度/时间），惯用手持内容手势在十个选项（CSL 0-9手势）中指定具体含义，仅需17个基础手势即可覆盖70个语义槽位。SentenceRecorder有限状态机管理IDLE→RECORDING→OUTPUT流程，TemporalSemanticParser通过最长后缀匹配将手势Token序列解析为语义链。对称双手控制手势（One=分隔符、Two=撤销词、Three=撤销句）内嵌于语义手势集。

**LLM增强层**：接入DeepSeek API进行语义重组与自然语言润色，支持手语翻译与AI导诊两种模式，四级优雅降级策略确保全条件下系统可用性。

**UI展示层**：Vue3单页应用+FastAPI WebSocket后端，Canvas骨架渲染，DL/规则双模式一键切换。

DL管线总参数量6.89M（E4主力模型），7.3M（E6含语义模态），均低于任务书10M上限，可在普通CPU上实现实时推理。

### 三、主要结果

在包含1,008条样本的自采集数据集（27种采集条件×15个手势变体，含同用户/跨用户/混淆对五维分层划分）上进行了全面实验验证：

**(1) 手势分类性能**：E6主力模型（Image+Skeleton+Semantic三模态）达到同用户99.2%、跨用户97.8%、混淆对89.6%的测试准确率。E4双模态模型（Image+Skeleton）同步达到同用户99.2%、跨用户94.4%、混淆对87.5%。

**(2) 消融实验（7组）**：核心发现——CNN不加几何约束导致跨用户崩盘（E1→E2: 87.8%→67.8%, -20pp），几何描述子恢复泛化（E2→E3: 67.8%→95.6%, +27.8pp），门控融合成功驯服CNN（E3→E4: 95.6%→94.4%, 仅-1.2pp），语义对比损失进一步提升跨用户（E4→E6: 94.4%→97.8%, +3.4pp）。

**(3) 关键机制验证**：GatedFusion门控网络将加性融合的29.5%崩溃修复至100%（E4训练记录），证明逐维选择性融合的必要性。对比损失使E6收敛速度优于E4（epoch 12 vs epoch 18达到98.2%）。

**(4) 系统性能**：检测>30 FPS（超任务书25 FPS要求），DL特征提取异步执行不阻塞主帧率，ONNX推理CPU可用。

### 四、结论与意义

本文提出了一套完整的轻量化多模态实时手语识别系统，通过"双手编码→手势Token→语义链→LLM润色"四级管道实现从原始手势到自然中文句子的端到端转换。五项核心创新：（1）双手组合编码协议——70语义槽仅需17个基础手势；（2）三模态多源融合——Image(CNN)+Skeleton(GCN+Geo)+Semantic(对比学习)，系统性消融实验验证各模态贡献与约束关系；（3）GatedFusion门控机制——从加性融合失败到门控成功的完整方法论；（4）29维几何描述子——结构化先验实现跨用户泛化关键；（5）场景可迁移架构——JSON配置零代码切换应用场景。系统为低成本、易部署的手语翻译与智能导诊工具提供了可行方案，在听障教育和医院无障碍沟通中具有实际应用价值。

## ABSTRACT

*(Times New Roman 三号, 段前后24磅, 全大写)*

### I. Background and Objective

Sign language is the primary communication modality for over 70 million deaf individuals worldwide. For native sign language users, keyboard input requires a cognitively demanding double conversion — from sign language concepts to Chinese grammatical structures, and then to character-level encoding — imposing high cognitive load and low expression efficiency. This thesis presents a lightweight multimodal real-time sign language recognition system based on the MediaPipe visual pipeline. The core interaction paradigm is a dual-hand combinatorial encoding protocol: the non-dominant hand selects one of seven semantic layers through mode gestures, while the dominant hand specifies meaning through one of ten content gestures, producing 70 semantic slots from only 17 base gestures.

### II. Methodology

The system adopts a seven-layer pipeline architecture. The Perception Layer uses MediaPipe HandLandmarker with wrist-centric normalization. The Feature Extraction Layer integrates three modalities: Image (MobileNetV3 CNN on hand ROI → 512-dim RGB texture), Skeleton (SpatialGCN + HandShapeContext with 29 geometric descriptors → 256-dim topology), and Semantic (SemanticProjector + InfoNCE contrastive loss for visual-semantic alignment). CNN and geometric features are merged via GatedFusion — a per-dimension learned gate σ(MLP([cnn; geo_proj])) that independently decides whether to trust texture or geometry. The CrossModalFusion (2-layer Transformer) produces a 256-dim unified representation. The Temporal Modeling Layer uses SlowFast TCN (dual-pathway temporal convolution) with temporal mean pooling for sequence-level classification. The Rule Recognition Layer provides a geometric decision tree with PIP error compensation for XAI. The Semantic Parsing Layer implements the dual-hand encoding protocol with a SentenceRecorder state machine and TemporalSemanticParser. The LLM Enhancement Layer integrates DeepSeek API with a four-level graceful degradation strategy. The UI Layer provides a Vue3 SPA with FastAPI WebSocket backend.

### III. Results

On a self-collected dataset of 1,008 samples with 27 acquisition conditions and 5-way stratified splits, the E6 model (Image+Skeleton+Semantic) achieves 99.2% in-user, 97.8% cross-user, and 89.6% confusion-pair accuracy. Seven ablation experiments reveal a causal chain: CNN without geometric constraints causes cross-user collapse (−20pp), geometric descriptors restore generalization (+27.8pp), GatedFusion successfully controls CNN degradation (−1.2pp vs −20pp), and semantic contrastive loss further boosts cross-user accuracy by +3.4pp. The system achieves >30 FPS detection, exceeding the 25 FPS requirement.

### IV. Conclusion

Five principal innovations: (1) dual-hand combinatorial encoding (70 slots from 17 gestures), (2) three-modality fusion with causal ablation analysis, (3) GatedFusion mechanism resolving additive fusion failure, (4) 29-dim geometric descriptors as the key to cross-user generalization, and (5) scene-transferable JSON-configurable architecture. The system provides a feasible solution for low-cost, deployable sign language translation and AI triage in healthcare accessibility contexts.

**Keywords**: sign language recognition; MediaPipe; dual-hand combinatorial encoding; graph convolutional network; SlowFast TCN; multimodal feature fusion; gated fusion; geometric descriptors; semantic contrastive learning; large language model; explainable AI; real-time system; AI triage
