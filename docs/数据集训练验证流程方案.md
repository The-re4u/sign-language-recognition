## 一、系统 DL 管线说明

### 1.1 管线架构

```
摄像头帧 (25fps)
      │
      ▼
MediaPipe HandLandmarker → 21 点关键点坐标 [21×3]
      │
      ├──→ [规则路径] RuleRecognizer → 16 种手势（当前生产路径）
      │
      └──→ [DL 路径]   SpatialGCN (0.15M) → 空间特征 [256维]
                        MotionEncoder (0.04M) → 运动特征 [128维]
                        CrossModalFusion (1.9M) → 融合特征 [256维]
                              │
                              ▼ 32 帧滑动窗口
                        SlowFast TCN (0.7M, ONNX) → 手势类别 + 置信度
```

总参数量：2.8M（远低于任务书 10M 要求）

### 1.2 DL 路径各模块

| 模块 | 功能 | 输入 | 输出 | 参数 |
|------|------|------|------|------|
| SpatialGCN | 图卷积编码手部骨骼拓扑 | [21,3] 关键点 | [256] 空间特征 | 0.15M |
| MotionEncoder | 编码关键点运动+光流 | 关键点差分+光流直方图 | [128] 运动特征 | 0.04M |
| CrossModalFusion | Transformer 跨模态融合 | 视觉+空间+运动 | [256] 融合特征 | 1.9M |
| SlowFast TCN | 双路径时序分类 | [T,256] 融合序列 | [T,200] 类别 logits | 0.7M |

### 1.3 规则 vs DL 对比

| 维度 | 规则识别 | DL 推理 |
|------|---------|---------|
| 原理 | 关节角度 >165° = 伸直 | 神经网络从数据学特征 |
| 训练 | 无需训练 | 需要标注数据训练 |
| 可解释 | ✅ 每步可追溯到关节角度 | ❌ 黑盒 |
| 速度 | <1ms | ~50ms (GCN+Fusion+TCN) |
| 论文价值 | 工程兜底 | **任务书核心要求** |

## 二、数据采集（自采集 + 合成增强）

### 2.1 真人自采集

```bash
python tools/record_data.py --output data/my_annotations.json --data_dir data/my_sequences
```

**操作流程**：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 运行命令，摄像头打开 | 均匀光照，手在画面中央 |
| 2 | 做手势（如 Closed_Fist） | 保持手势稳定 |
| 3 | 按 SPACE 开始录制 | 保持 2-3 秒 |
| 4 | 再按 SPACE 结束 | |
| 5 | 按数字键标注 | `0`=Closed_Fist `1`=Good `2`=Thumb_Down `3`=One `4`=Two `5`=Victory `6`=Eight `7`=Six `8`=Three `9`=Four `p`=Space `o`=Open_Palm |
| 6 | 重复 2-5 | 每种手势 50 次 |

**采集策略（确保泛化能力）**：

| 变量 | 变化 | 每组 |
|------|------|------|
| 距离 | 30cm / 50cm / 80cm | 各 ~15 次 |
| 旋转 | 正对 / 左偏15° / 右偏15° | 各 ~15 次 |
| 光照 | 明亮 / 正常 / 偏暗 | 各 ~15 次 |

**产出**：12 手势 × 50 次 = **600 条**自采 .npy 序列

### 2.2 合成数据增强

```bash
python tools/generate_synthetic_data.py \
    --output data/synthetic.json \
    --data_dir data/syn_sequences \
    --samples 80
```

**已内置域随机化**：

| 随机化 | 参数 | 概率 |
|--------|------|------|
| 关键点抖动 | σ=0.008-0.012 | 100% |
| 手指遮挡 | 随机置零 1-5 个关键点 | 30% |
| 低光照 | jitter 增大至 0.015-0.030 | 40% |
| 旋转+缩放 | ±3° / ±3% | 100% |

**产出**：12 手势 × 80 样本 = **960 条**合成序列

### 2.3 合并数据集

```python
import json

with open('data/my_annotations.json') as f:
    real = json.load(f)
with open('data/synthetic.json') as f:
    syn = json.load(f)

merged = real + syn
with open('data/dataset_full.json', 'w', encoding='utf-8') as f:
    json.dump(merged, f, ensure_ascii=False, indent=2)

print(f'{len(merged)} samples ({len(real)} real + {len(syn)} synthetic)')
```

**最终数据集**：600 自采 + 960 合成 = **1,560 条标注样本**

## 四、模型训练

### 4.1 训练命令

```bash
# 多模态训练（关键点 + RGB 视觉，任务书要求）
python tools/train.py \
    --data data/dataset_full.json \
    --data_dir data/my_sequences \
    --epochs 100 \
    --batch_size 8 \
    --lr 1e-4 \
    --use_visual \
    --output models/checkpoints
```

### 4.2 训练参数字典

| 参数 | 值 | 作用 |
|------|-----|------|
| 优化器 | AdamW | 自适应 + 权重衰减 |
| 学习率 | 1e-4 | 稳定收敛 |
| 权重衰减 | 1e-4 | 防过拟合 |
| Batch size | 16 | 匹配 ~1500 条数据量 |
| Epoch | 100 | 充分训练 |
| 学习率调度 | 5 epoch 预热 + Cosine 退火 | 前期稳定 + 后期精细 |
| 混合精度 | AMP (FP16) | 加速 + 省显存 |
| 梯度裁剪 | max_norm=1.0 | 防梯度爆炸 |
| 损失函数 | CE Loss + 时间均值池化 | 序列→单标签分类 |
| Checkpoint | 每 10 epoch 保存 | 可恢复 |

### 4.3 收敛判定

| 指标 | 未训练 | 收敛 |
|------|--------|------|
| Loss | >5.0 | <1.0 |
| 训练准确率 | ~6% (随机) | >85% |
| 验证准确率 | ~6% | >75% |

### 4.4 导出 ONNX

```bash
python tools/export_onnx.py \
    --checkpoint models/checkpoints/best_model.pth \
    --output models/sign_recognizer.onnx
```

导出后服务自动加载新模型，切到 DL 模式即可使用。
