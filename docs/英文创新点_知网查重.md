# Innovation Points (English)

**Title**: Design and Implementation of a Lightweight Multimodal Real-Time Sign Language Recognition System

---

## Innovation Points

**1. Dual-Hand Combinatorial Encoding Protocol.** A novel human-computer interaction paradigm is proposed that treats sign language gestures as compositional linguistic tokens rather than isolated visual patterns. By separating mode selection (non-dominant hand, 7 semantic layers) from content specification (dominant hand, 10 options), the system achieves 70 unambiguous semantic slots from only 15 base gestures — a 4.7-fold encoding efficiency improvement over conventional one-to-one gesture mapping. Symmetric dual-hand control gestures (undo-word, undo-sentence, manual separator) are embedded within the same gesture vocabulary with zero ambiguity, eliminating the need for external input devices or mode-switching buttons. The SentenceRecorder finite state machine manages the complete sentence-level recording lifecycle with configurable hold-duration, inter-gesture cooldown, and idle timeout constraints.

**2. Rule/DL Dual-Mode Complementary Architecture with XAI Compliance.** A dual-mode recognition architecture is designed in which a geometric rule engine and a deep learning model share a common downstream semantic pipeline with one-click switching. The rule engine employs clinically validated goniometric thresholds (finger extension >165°, MCP-PIP-DIP joint angle measurement) and PIP/MCP dual-channel verification — compensating for the PIP joint's documented 20–30° tracking error through auxiliary MCP-based cross-checking with a 12% confidence penalty — to achieve fully explainable AI (XAI) compliance where every classification decision is traceable to specific joint angle measurements. The DL model learns user-specific anatomical features from data, achieving 82.8% test accuracy (51.7 percentage points above the rule engine baseline on real user data). The two approaches exhibit complementary error patterns, motivating their coexistence for both auditable production use and accuracy-optimized enhancement.

**3. Multimodal Lightweight Feature Fusion with Quantitative Modality Validation.** Three modality-specific encoders — SpatialGCN (graph convolutional network, 0.15M parameters) encoding hand skeletal topology with an auxiliary angle encoder that explicitly injects 10 inter-joint geometric priors, MotionEncoder (0.04M) capturing inter-frame dynamics through keypoint velocity fields and optical flow histograms with learned three-path adaptive fusion, and LightweightVisualEncoder (MobileNetV3-Small frozen backbone, 0.15M trainable) extracting ROI appearance features — are integrated through a CrossModalFusion module (2-layer Transformer Encoder with learnable modality type embeddings, 1.9M). Total trainable parameters are 2.8M (72% of the 10M task budget), enabling CPU-only real-time inference via ONNX Runtime. Systematic ablation experiments provide quantitative evidence for each modality's unique contribution: GCN spatial topology is foundational (76.6 pp contribution, removal causes collapse to near-random 6.2%), motion dynamics are substantial (31.6 pp, capturing within-pose micro-dynamics such as tremors and stabilization patterns even in static gesture recognition), and visual texture is complementary (9.6 pp).

**4. Scene-Transferable Architecture with JSON-Driven Configuration.** The seven-layer pipeline is designed with a strict separation between scene-agnostic gesture recognition (layers 1–4: perception, feature extraction, temporal modeling, rule recognition) and scene-specific semantic interpretation (layers 5–6: semantic parsing, LLM enhancement). All semantic mappings, chain rules (40 general-purpose + 65 hospital-specific chains), and LLM system prompts are defined through replaceable JSON configuration files. Migrating the system from hospital triage to banking services, airport information, smart home control, or government services requires only configuration file replacement — zero code modification. This architectural principle transforms the system from a single-scene prototype into a general-purpose sign language communication framework.

**5. End-to-End Gesture-to-Language Pipeline with LLM-Enhanced Multi-Turn Triage.** Beyond conventional isolated gesture classification, the system achieves complete conversion from raw hand movements through dual-hand combinatorial encoding and semantic chain parsing to natural Chinese sentences. A large language model (DeepSeek API) is integrated at the pipeline terminus for semantic reassembly (word reordering, sentence completion, numerical parsing, register adaptation) and multi-turn AI triage consultation (symptom inquiry → closed-ended follow-up questions → department recommendation). A four-level graceful degradation strategy ensures system availability under all conditions: Level 1 (LLM polished output), Level 2 (chain-matched base sentence on API timeout), Level 3 (raw token concatenation on no chain match), and Level 4 (rule-engine-only operation on complete DL/API failure). This integration of LLM-based semantic interpretation into a gesture recognition pipeline represents a novel contribution toward bridging the gap between pattern recognition and practical communication.
