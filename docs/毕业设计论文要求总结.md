# 本科毕业设计说明书（论文）完整要求总结

> 适用专业：软件工程（中外合作办学）  
> 学院：计算机科学与技术学院、软件学院

---

## 一、封面信息要求

封面须包含以下字段，填写完整：

| 字段 | 说明 |
|------|------|
| 论文题目（中文） | 居中，醒目 |
| 论文题目（英文） | 全大写，居中 |
| 学院 | 填写所在学院名称 |
| 专业 | 填写具体专业名称 |
| 班级 | 填写所在班级 |
| 学号 | 填写学号 |
| 学生姓名 | 填写学生姓名 |
| 指导老师 | 填写导师姓名 |
| 提交日期 | 填写年月，格式如：2026年3月 |

---

## 二、整体结构要求

论文须按以下顺序组织：

```
封面
中文摘要（摘要 + 关键词）
英文摘要（ABSTRACT + Keywords）
目录（CONTENT）
正文各章（CHAPTER 1 ~ CHAPTER N）
参考文献（Reference）
致谢（Acknowledgment）
```

---

## 三、格式要求（详细）

### 3.1 摘要（中文）

- **"摘要"二字**：黑体，三号，段前段后均设置为 **24磅**
- **摘要内容**：宋体，小四，多倍行距 **1.25**
- **结构建议**：分三段
  - 第一段：整体介绍论文主题（topic）
  - 第二段：总结核心算法及验证结果
  - 第三段：总结基于算法开发的系统
- **"关键词"三个字**：宋体，小四，**加粗**
- **关键词数量**：三个以上，以逗号分隔

### 3.2 英文摘要（ABSTRACT）

- **"ABSTRACT"**：Times New Roman，三号，段前段后 **24磅**（全大写）
- **摘要内容**：Times New Roman，小四，多倍行距 **1.25**
- **结构**：与中文摘要对应，分三段
- **"Keywords"**：Times New Roman，小四，加粗

### 3.3 目录（CONTENT）

- **"CONTENT"**：全大写，三号，段前段后 **24磅**
- **目录内容**：**自动生成**（不可手动输入），根据正文标题自动提取
- **字体**：目录生成后，将字体统一修改为 **Times New Roman，小四**
- 若章节安排与模板不同，可复制正文标题进行增删，以保持格式一致

### 3.4 章标题（一级标题）

- 格式：`CHAPTER X: TITLE`（如 `CHAPTER 1: INTRODUCTION`）
- 字体：**Times New Roman，三号，加粗**
- 段前段后：**24磅**
- **分页要求**：每章开始前，必须在上一章最后一页末尾插入**分页符**，确保每章从新页开始

### 3.5 节标题（二级标题）

- 格式：`X.X Title`（如 `1.1 Background`）
- 字体：**Times New Roman，四号，加粗**
- 段前段后：**12磅**

### 3.6 小节标题（三级标题）

- 格式：`X.X.X Title`（如 `2.1.1 Traditional Machine Learning`）
- 字体：**Times New Roman，小四，加粗**
- 段前段后：**12磅**

### 3.7 正文内容

- 字体：**Times New Roman，小四**
- 行距：**多倍行距 1.25**
- 对齐方式：**两端对齐**
- 语言：全文使用**英文**撰写

### 3.8 图（Figure）

- 命名规则：按章节顺序编号，格式为 `Figure X-Y`
  - 例：第一章第一张图命名为 `Figure 1-1`，第三章第二张图命名为 `Figure 3-2`
- 图题位于图片下方，居中
- 若图片来源于文献，**必须标注引用**（否则视为抄袭）
  - 格式示例：`Figure 2-5: Residual learning from [26]`

### 3.9 表（Table）

- 命名规则：与图类似，按章节顺序编号，格式为 `Table X-Y`
  - 例：`Table 3-4: Definition of TP, TN, FP and FN`
- 表题位于表格上方

### 3.10 公式

- 公式须编号
- 变量须在文中说明

## 四、各章节内容要求

### 第一章 INTRODUCTION（引言）

| 小节 | 内容说明 |
|------|---------|
| 1.1 Background | 写论文 topic 对应的背景，可引用相关文献 |
| 1.2 Purpose and Significance | 写项目的研究意义与研究目标 |
| 1.3 About System | 介绍开发环境，包括后端语言/框架、前端框架、数据库、GPU等 |
| 1.4 Organization of This Article | 逐章介绍各章的主要内容 |
| 1.5 Chapter Summary | **每章必须有小结**，概括本章主要内容 |

### 第二章 RELATED WORK（相关工作）

- 总结与项目所用技术/算法相关的国内外研究现状
- 介绍相关基础概念与技术原理
- 可包含：传统方法综述、深度学习方法综述、趋势分析
- 可使用对比表格归纳各文献的方法与指标
- 章节末尾需有 **Chapter Summary**

### 第三章 核心算法章（论文重点章）

> 这是论文最重要的章节，需写得清晰、丰富、完整。

必须包含：

- **算法总体思路**（Overall Idea）：配流程图
- **算法细节说明**：可配伪代码、公式、结构图等
  - 若使用现有算法：结合自身应用讲清楚
  - 若有改进：**必须清晰说明改进点**
- **实验与分析**（Experiments and Analysis）：
  - 实验部分须放在算法讲解之后，**不要单独成章**
  - 数据集介绍（Dataset）
  - 评价指标说明（Evaluation Criteria）
  - 参数对比实验（消融实验）
  - 与其他方法对比实验
  - 结果分析（图表结合）
- **Chapter Summary**

### 第四章 SYSTEM DESIGN AND DEVELOPMENT（系统设计与开发）

必须涵盖：

| 内容 | 说明 |
|------|------|
| 需求分析 | 功能性需求（Functional）+ 非功能性需求（Non-functional）|
| 系统上下文 | 系统涉及的用户、外部系统，可用上下文图表示 |
| 系统功能设计 | 每个功能模块用用例图（Use Case Diagram）或时序图（Sequence Diagram）说明 |
| 系统界面介绍 | 主界面 + 各功能模块界面 + 个人主页界面，配截图说明 |
| Chapter Summary | |

> ⚠️ 注意：本章给出的内容仅为参考，**严禁抄袭**，一经发现取消毕设成绩。

### 第五章 CONCLUSION AND FUTURE WORK（总结与展望）

| 小节 | 内容说明 |
|------|---------|
| 5.1 Conclusion | 总结本文完成的工作，包括算法创新点与系统功能 |
| 5.2 Future Work | 对后续工作进行展望，列出若干改进方向 |

---

## 五、参考文献要求

- 数量：**30个以上**
- 格式：按文中引用顺序标注，从 [1] 开始顺序编号
- 文中引用格式：`[序号]`，如 `[1]`、`[2, 3]`，按顺序标注，**不可乱序**
- 参考文献来源需真实，格式规范（参照IEEE或标准学术格式）
- 若图/表来源于他人文献，**正文中必须同步标注引用**

---

## 六、引用规范说明

- 引用须在正文中对应位置用 `[序号]` 标注
- 来自他人论文的图片，标题后须写明来源，如：`Figure X-X: xxx from [N]`
- **严禁使用未标注来源的他人图片或文字**（视为学术不端）

---

## 七、其他注意事项

| 事项 | 要求 |
|------|------|
| 每章分页 | 每章开头前插入分页符，新章从新页开始 |
| 目录自动生成 | 禁止手动输入目录，必须由Word自动提取正文标题生成 |
| 每章末尾小结 | 每一章都必须有 Chapter Summary 小节 |
| 实验章节位置 | 实验部分跟随算法章，不单独成章 |
| 内容独创性 | 系统设计与开发章节内容不得抄袭模板示例 |
| 数据集说明 | 若使用非公开数据集，需说明来源及伦理合规情况 |
| 语言 | 正文全部使用英文撰写 |
