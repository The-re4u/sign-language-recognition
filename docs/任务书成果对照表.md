## 二、核心成果速览

### 系统能力

| 功能 | 说明 |
|------|------|
| 实时手势识别 | 15种手势（7模式+10内容），规则/DL双模式一键切换 |
| 双手组合编码 | 左手选语义层+右手选含义=70个语义槽位，4.7倍编码效率 |
| 自然语言输出 | 手势Token→语义链匹配→DeepSeek润色→自然中文句子 |
| AI导诊 | 多轮症状追问（是/否）+科室推荐 |
| 场景可迁移 | JSON配置替换即可适配银行/机场/智能家居/政务等场景 |

### 实验数据

| 指标 | 值 | 说明 |
|------|-----|------|
| DL测试准确率 | **82.8%** | 真人测试集209样本13类 |
| 规则引擎（合成） | **97.6% F1** | 378条合成样本 |
| 规则引擎（真人） | 31.1% | 硬编码阈值不泛化——DL提升51.7pp |
| 消融：GCN贡献 | **-76.6pp** | 移除后模型崩溃至6.2% |
| 消融：运动编码贡献 | **-31.6pp** | 移除后降至51.2% |
| 消融：视觉编码贡献 | **-9.6pp** | 移除后降至73.2% |
| 检测速度 | **31.7 FPS** | >任务书25 FPS |
| 处理延迟 | **32.1ms** | 端到端平均 |
| 模型参数 | **3.4M** | 可训练，<任务书10M |

### 对比：规则 vs DL

| 模型 | 准确率 | 参数量 | 推理 | 可解释性 |
|------|--------|--------|------|---------|
| 规则引擎 | 31.1%（真人）| 0 | <1ms | ✅ XAI |
| DL多模态 | **82.8%**（真人）| 3.4M | ~50ms | 黑盒 |

### 主要创新

1. **双手组合编码协议** — 15手势→70语义槽位，模式切换自动分隔
2. **规则/DL双模式互补** — XAI+数据驱动共存，互补误差模式
3. **多模态轻量化融合** — 3.4M参数CPU实时，消融量化各模态贡献
4. **场景可迁移架构** — JSON配置，零代码切换应用场景
5. **手势→语言完整闭环** — 分类→语义→LLM润色→多轮导诊
